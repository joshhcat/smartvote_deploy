SMARTVOTE

SmartVote is an online voting system designed to make the voting process easier, faster, and more secure.
Facial Recognition
-Voters capture their face using a camera during account registration and it will verify your face if sumbit a vote to ensure youre the one who cast the votes.
Voter Registration
-Users can create an account to become a voter.
Login and Authentication
-Voters securely log in to the system.
Candidate List Viewing
-Voters can see the list of candidates and their details.
Online Voting
-Voters can select and submit their votes electronically.
One Vote Per Voter
-The system ensures each voter can vote only once.
Vote Counting
-The system automatically counts the votes.
Real-Time Results
-Admins can see the election results instantly.
Admin Dashboard
-Admins can manage voters, candidates, and elections.
Election Management
-Admins can create, start, or end elections.
